### Post A — Agent vs chatbot (ship first) ✅ live

Chatbots answer. Agents act—with tools and human gates.

If your team keeps saying “we need an AI agent” but the job is FAQ replies from a handbook, start with a grounded assistant. If the job is create a ticket, look up CRM state, and wait for approval before a write—that’s an agent.

### Post B — RAG vs fine-tuning

Private docs change weekly. Fine-tuning bakes yesterday into weights. RAG retrieves today’s passages and cites them.

Default for most SMB knowledge problems: retrieval first. Fine-tune only when a clear metric says prompting + RAG are not enough.

Guide: https://www.trevyk.in/work/rag-vs-fine-tuning
